# Mursion

> Mursion is an AI-powered immersive upskilling platform that trains workforce soft skills —
> leadership, customer service, sales, healthcare communication and difficult conversations —
> through simulated conversations with virtual avatars. Simulations run either human-powered
> (Mursion Live, a certified Simulation Specialist puppets the avatar in real time) or AI-powered
> (Mursion On-Demand). Delivery and administration happen in the Mursion Portal, a browser-based
> web application.

Important for agents: **Mursion publishes no public API.** There is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no MCP server and no agent card. The
backend that serves the Mursion Portal (https://apiaws.mursion.com) is an AWS API Gateway that
returns HTTP 403 `{"message":"Missing Authentication Token"}` on every path. Do not attempt to
construct calls against it. The only publicly documented integration surface is enterprise
single sign-on.

## Integration surface

- [Configuring SSO for Mursion](https://support.mursion.com/knowledge/configuring-an-sso-for-mursion):
  overview of the tenant SSO setup an account owner performs.
- [Configuring SAML 2.0](https://support.mursion.com/knowledge/configuring-saml-2.0): Mursion acts
  as the SAML 2.0 Service Provider. SP-initiated SSO, JIT provisioning, required claims
  `email`, `firstName`, `lastName`, NameID format
  `urn:oasis:names:tc:SAML:1.1:nameid-format:unspecified`.
- [Configuring OpenID Connect with Okta](https://support.mursion.com/knowledge/configuring-openid-connect-with-okta):
  Mursion acts as the OIDC Relying Party. Scopes `openid profile email`; claims `sub`, `email`,
  `given_name`, `family_name`; SP- and IdP-initiated SSO; JIT provisioning.
- [Team assignment via SSO](https://support.mursion.com/knowledge/team-assignment-via-sso):
  an optional configurable IdP claim maps a user onto a Mursion team.
- [SAML 2.0 with Okta](https://support.mursion.com/knowledge/configuring-saml-2.0-with-okta),
  [with Microsoft Entra ID](https://support.mursion.com/knowledge/configuring-saml-with-microsoft-entra-id),
  [with Azure AD](https://support.mursion.com/knowledge/configuring-saml-2.0-with-microsoft-azure-ad).
- [Network and technical requirements](https://support.mursion.com/knowledge/ai-powered-simulations-tech-implementation-and-network-requirements):
  allowlist `*.livekit.cloud`, `*.turn.livekit.cloud`, `*.host.livekit.cloud`; TCP 443, UDP 3478,
  TCP/UDP 7881 and 50000-60000, plus 49152-65535 to the published IPv4 set. Media is WebRTC via LiveKit.
- [Connection test](https://connection-test.mursion.com/): self-service readiness diagnostic.
